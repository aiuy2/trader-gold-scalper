# TRADER GOLD SCALPER — واجهة الويب

واجهة ويب متجاوبة (تفتح من Chrome على الموبايل أو أي متصفح ديسكتوب) تتصل مباشرة
بـ `backend/` عبر REST + WebSocket. بدون أي أدوات بناء (build tools) — HTML/CSS/JS
عادي، تفتحها وتشتغل.

## التشغيل خطوة بخطوة

### 1) شغّل السيرفر (backend)
```bash
cd TRADER
pip install -r requirements.txt --break-system-packages
uvicorn backend.app.main:app --reload --port 8000
```
السيرفر يشتغل افتراضياً بوضع `mock` (بدون حساب MT5 حقيقي) — يعني تقدر تجرب
تشغيل/إيقاف البوت ومشاهدة صفقات وهمية فوراً بدون أي إعداد إضافي.

### 2) اضبط رابط الـ API في الواجهة
افتح `frontend/js/config.js` وتأكد إن `API_URL` يشاور على عنوان السيرفر:
- تجربة على نفس الجهاز: `http://localhost:8000` (القيمة الافتراضية)
- من جهاز ثاني بنفس الشبكة: استخدم IP الجهاز، مثلاً `http://192.168.1.10:8000`
- سيرفر منشور فعلياً على الإنترنت: رابط الدومين، مثلاً `https://api.example.com`

### 3) افتح الواجهة
أبسط طريقة — شغّل سيرفر ثابت بسيط من داخل مجلد `frontend`:
```bash
cd frontend
python3 -m http.server 5173
```
وبعدين افتح من Chrome: `http://localhost:5173`

> ملاحظة: فتح `index.html` مباشرة بصيغة `file://` قد يمنع بعض المتصفحات طلبات
> الشبكة (CORS/Service Worker)، لذلك يُفضّل دائماً تشغيله عبر سيرفر ولو بسيط.

### 4) تثبيت التطبيق كـ PWA على أندرويد
من Chrome، افتح رابط الواجهة → قائمة الثلاث نقاط ⋮ → **"إضافة إلى الشاشة الرئيسية"**
(Add to Home screen). بيفتح بعدها بشكل مستقل مثل تطبيق حقيقي بدون شريط عنوان.

## الشاشات المتوفرة
- **تسجيل الدخول / إنشاء حساب** — يبدأ كل حساب جديد بترخيص تجريبي 7 أيام تلقائياً.
- **لوحة التحكم** — حالة البوت (نبض حي)، تشغيل/إيقاف، إحصائيات الأداء، حد الخسارة اليومي، المراكز المفتوحة.
- **الصفقات** — سجل كامل للصفقات المغلقة.
- **الإعدادات** — إعدادات المخاطرة والرمز واللوت، وربط حسابات MT5.
- **الترخيص** — عرض الترخيص الحالي وتفعيل مفتاح جديد.

تحديثات الصفقات وحالة البوت تصل فوراً عبر WebSocket (بدون تحديث الصفحة).

## قبل النشر الفعلي (production)
- غيّر `allow_origins=["*"]` في `backend/app/main.py` إلى رابط الواجهة الحقيقي فقط.
- غيّر `JWT_SECRET` في `.env` إلى قيمة عشوائية قوية.
- شغّل الواجهة عبر HTTPS (شرط أساسي لتثبيت PWA وعمل Service Worker بشكل كامل خارج localhost).
